# ARCAUR website

The first one-page ARCAUR website trial.

## Current direction

- Premium navy, gold, and warm ivory visual identity
- One-page hospitality supply presentation
- Wooden acoustic wall panel as the first featured product
- Product photography and contact details intentionally marked for later replacement

## Local development

Requires Node.js 22 or newer.

```bash
npm install
npm run dev
```

Build the site with:

```bash
npm run build
```
